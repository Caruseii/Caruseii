<h2>Sobre mim</h2>

<p>Oi, eu sou o <b>Carusei</b>, de Santa Catarina. Estudo <b>Desenvolvimento Full Stack</b> e <b>Design</b> na <a href="https://ebaconline.com.br">EBAC</a>, e faço os dois cursos completos. Escolhi estudar as duas áreas juntas porque gosto de acompanhar uma ideia do começo ao fim: primeiro desenho como ela deve ser, depois escrevo o código que a coloca no ar.</p>

<p>No <b>Design</b>, aprendo a pensar em layout, cores, tipografia e na experiência de quem vai usar. No <b>Full Stack</b>, aprendo a construir o que fica na frente (as telas) e o que fica por trás (a lógica e os dados) para que tudo funcione de verdade. Ter as duas visões me ajuda a criar interfaces que, além de bonitas, são simples de usar e fáceis de manter.</p>

<p>Aqui no GitHub eu guardo os projetos que faço durante os cursos e os que crio por conta própria para praticar. Estou sempre estudando, errando, corrigindo e melhorando um commit de cada vez.</p>
